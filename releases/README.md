# 📦 SnapClip Pre-compiled Release Binaries

This directory contains direct 1-click pre-compiled binaries for SnapClip V1.

---

## 💻 1. Windows PC Desktop Agent (`.exe`)

* **Filename**: [`SnapClip-Desktop-Agent.exe`](SnapClip-Desktop-Agent.exe)
* **Size**: ~28.9 MB
* **Requirements**: Windows 10 or Windows 11 (64-bit)

### How to Run:
1. Click [`SnapClip-Desktop-Agent.exe`](SnapClip-Desktop-Agent.exe) to download/run directly on your Windows PC.
2. Double-click the file to open the SnapClip Desktop Agent.
3. No Python installation or command prompt required!

---

## 📱 2. Android Mobile App (`.apk`)

* **Filename**: `SnapClip-Android.apk`
* **Requirements**: Android 8.0+

### How to Install:
1. Download `SnapClip-Android.apk` directly to your phone.
2. Tap the file in your phone Downloads to install.
