# 📦 SnapClip Pre-compiled Binaries (V1 Release)

Both pre-compiled 1-click installer binaries for SnapClip are committed directly inside this repository.

---

## 📱 1. Android Mobile App (`.apk`)

* **File**: [`SnapClip-Android.apk`](SnapClip-Android.apk) (~174 MB)
* **Target OS**: Android 8.0 or newer
* **Permissions**: Wi-Fi / Internet & Camera (for QR pairing)

### Installation Steps:
1. Download [`SnapClip-Android.apk`](SnapClip-Android.apk) directly onto your Android phone.
2. Tap the downloaded file in your phone's **Downloads** folder.
3. If prompted by Android, enable **"Allow from this source"** to install.
4. Open **SnapClip** on your phone!

---

## 💻 2. Windows PC Desktop Agent (`.exe`)

* **File**: [`SnapClip-Desktop-Agent.exe`](SnapClip-Desktop-Agent.exe) (~28.9 MB)
* **Target OS**: Windows 10 or Windows 11 (64-bit)

### Installation Steps:
1. Download [`SnapClip-Desktop-Agent.exe`](SnapClip-Desktop-Agent.exe) onto your Windows PC.
2. Double-click the file to start the desktop agent.
3. No Python, setup, or command prompt required!
